# 签迹 CheckinTrace

一个在 Android 本地运行的游戏社区每日签到工具。目前支持米游社与森空岛，可自行选择游戏和每日执行时间。

> 项目仍处于测试阶段。第三方平台的接口、登录流程和风控策略可能随时变化，请只在自己的账号上谨慎使用。

## 功能

- 米游社使用已验证可用的电脑/通行证二维码登录；取得凭证后，签到独立使用 Android 设备登记与 Android 请求头
- 支持原神、崩坏：星穹铁道、绝区零、崩坏 3、未定事件簿和崩坏学园 2
- 森空岛使用官方二维码登录，支持明日方舟与明日方舟：终末地
- 森空岛长期加密保存 access token、cred 与 sign token；按需刷新 sign token，明确鉴权失效时最多重建一次完整凭证
- 森空岛签到接口即使以 HTTP 403 返回，只要业务正文明确表示“请勿重复签到/今日已签到”，仍按今日已签到处理；其他 403 才按平台拒绝停止后续请求
- 手动签到成功后记录当天完成状态，计划任务会跳过已完成游戏
- 自动任务保存执行进度，已提交但结果未知的角色不会自动重复提交
- Debug 测试包使用固定签名，可在固定签名版本之间直接覆盖升级
